Perception → reasoning → execution

One responsibility per agent.

All stages exchange structured artifacts through a shared Project State. Deterministic services execute the media plan.

01 · PERCEIVE

Vision

Segment rooms and extract visible facts into a reusable scene inventory.

02 · PLAN

Planner

Interpret the brief and choose highlights, attention, and narrative order.

03 · WRITE

Script

Generate scene-grounded narration with coverage and duration checks.

04 · DIRECT

Voice

Plan speech style and pronunciation for a separate TTS execution service.

05 · ALIGN

Timeline

Align footage and measured speech durations within the video budget.

06 · EDIT

Editing

Specify pacing, transitions, subtitles, visual treatment, and audio strategy.

07 · EXECUTE

Rendering

Turn the structured editing plan into an MP4 with deterministic operations.

08 · REVIEW

Evaluation

Check alignment and quality, then route a bounded correction pass.

Footage + brief → scene facts → story + script → timed speech → editing plan → rendered video → quality review
