# Content Planner - Plan Prompt

Version: 1.0.0

## Task

Create a content plan for the real estate video based on the vision analysis.

## Input

- Vision analysis: {vision_json}
- User prompt: {user_prompt}
- Property metadata: {property_metadata}

## Instructions

1. Review all segments from the vision analysis
2. Rank each segment by importance (0.0 to 1.0)
3. Identify key focus points for each segment
4. Assign target durations that reflect importance
5. Determine the overall narrative arc
6. List the top property highlights

## Guidelines

- Kitchens and living rooms typically have high importance
- Bathrooms and utility rooms have lower importance unless luxurious
- Total duration should match user expectations
- Prioritize unique selling features
- Ensure narrative flow from room to room makes spatial sense
